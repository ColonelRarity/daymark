# Daymark

Додаток для iOS і Android: ціль за днем, щоденник харчування, рух і рамки дієт. Це початок продукту. Концепт лишається в `concept/` і не є збіркою для App Store.

Репозиторій: https://github.com/ColonelRarity/daymark

## Як відкрити

Концепт у браузері:

```bash
npm run concept
```

Далі відкрий http://localhost:4173

Мобільний каркас у браузері (той самий код піде на iOS і Android через Expo):

```bash
cd mobile
npm run web
```

На телефоні: `npm run ios` або `npm run android` у папці `mobile`, коли стоять Xcode або Android Studio.

Перевірки:

```bash
npm test
npm run test:concept
```

## Що всередині

- `concept/` — клікабельний веб-концепт: календар цілі, щоденник, 100 рецептів, 3 815 позицій їжі, напої, рух.
- `mobile/` — Expo-застосунок. У щоденнику вже рахуються олія для смаження і соус за грамами. Окремі вкладки є для закладів і дієт.

База інших застосунків сюди не копіюється. Числа беруться з названого джерела: Ciqual 2025 і офіційні сторінки закладів. Невідомий нутрієнт лишається невідомим.
